### Tips
If you have other things in your build tools(Gradle/Maven) DONT REPLACE THE WHOLE THING, if you are a beginner ask AI if udk.

### Gradle
Add these code to your build.gradle
```
repositories {
    mavenCentral()
    maven { url 'https://jitpack.io' }
}
```
```
dependencies {
    implementation 'com.github.EXEFile7f3c9d8a:Vren:main-SNAPSHOT'
}
```
### Maven
If you are maven add these to pom.xml
```
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>
```
```
<dependencies>
    <dependency>
        <groupId>com.github.EXEFile7f3c9d8a</groupId>
        <artifactId>Vren</artifactId>
        <version>main-SNAPSHOT</version>
    </dependency>
</dependencies>
```
